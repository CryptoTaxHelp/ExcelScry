Why "Make default" opens Windows Settings

Installing the Scry Excel File context-menu entry works directly, and the installer does that for you. Becoming the program that opens .xlsx, .xlsm and .xls by default is different: since Windows 8 the choice is stored in a hash-protected UserChoice key that only Windows itself may write. An installer that fakes it is silently ignored, so ExcelScry registers itself as a candidate and hands you the one-click confirmation in Settings › Apps › Default apps instead.

On Windows 11 you will find the context-menu entry under Show more options (Shift+F10).

What this workbook carries

Why this is worth knowing

Macros, external links, data connections, embedded objects and ActiveX controls are all things a workbook can use to run code or fetch data when it is opened in Excel or LibreOffice. They are not part of the cell values, so ExcelScry shows the workbook without touching them.

This is a description of the file, not a scan for malware. Open a workbook in Excel only if you trust where it came from.
